# लोराकोड 3.40.0

**एंड्रॉइड के लिए मोबाइल लिनक्स कार्यक्षेत्र** - एक एप्लिकेशन में उबंटू, नोड.जेएस, एनपीएम, पायथन और वैकल्पिक काली लिनक्स।

> अपडेट किया गया: 11 अगस्त 2026। पृष्ठभूमि में लंबे समय तक इंस्टॉलेशन जारी रहता है, लेकिन लोराकोड को जबरदस्ती नहीं रोका जाना चाहिए।

## नया क्या है

- एक अलग, आधुनिक एजेंट कार्यक्षेत्र के साथ टर्मिनल के ठीक नीचे **लोरा एआई** जोड़ा गया।
- पहला लॉन्च ओपनएआई, क्लाउड, ग्रोक, जेमिनी, ओपनकोड ज़ेन और किसी भी ओपनएआई-संगत कस्टम प्रदाता का समर्थन करता है। एपीआई कुंजी एंड्रॉइड कीस्टोर द्वारा एन्क्रिप्ट की गई हैं।
- लोरा एआई में उबंटू होम या फोन स्टोरेज के लिए प्रोजेक्ट चयन, लगातार चैट, एक एकीकृत टेक्स्ट एडिटर और एक स्लाइडिंग फ़ाइल/वर्कस्पेस मेनू शामिल है।
- वास्तविक टूल कॉलिंग फ़ाइलों या फ़ोल्डरों को सूचीबद्ध कर सकती है, पढ़ सकती है, खोज सकती है, बना सकती है, बदल सकती है, स्थानांतरित कर सकती है, नाम बदल सकती है और हटा सकती है और POSIX अनुमतियाँ बदल सकती है। प्रत्येक पथ चयनित प्रोजेक्ट तक ही सीमित है और परिवर्तन डिफ़ॉल्ट रूप से अनुमोदन मांगते हैं।
- प्रदाता समापन बिंदु/मॉडल, प्रति-टूल अनुमति समूह, अनुमोदन मोड और ऑटो सेव को बाद में लोरा एआई प्राथमिकताओं से बदला जा सकता है।
- सिस्टम विवरण को लाइव पैकेज रिफ्रेश, रनटाइम कार्ड, खोज, श्रेणी गणना और एपीटी अपडेट-उम्मीदवार संकेतक के साथ फिर से डिजाइन किया गया था।
- वेब कंसोल अब लोराकोड के वीटी इंजन, सटीक ब्राउज़र आकार, थीम वाले रंग और मोबाइल शॉर्टकट का उपयोग करता है, इसलिए ओपनकोड एएनएसआई कलाकृतियों के बिना प्रस्तुत करता है।
- वेब कंसोल अब वर्तमान कमांड को मोबाइल कीबोर्ड के ऊपर दृश्यमान रखता है, इसे एंटर के साथ सबमिट करता है और स्थानीय कमांड इतिहास प्रदान करता है।
- क्रोमियम/ब्रेव में वेब कंसोल कनेक्शन, मोबाइल कीबोर्ड फोकस, आईएमई संरचना और स्वचालित पुन: कनेक्शन को ठीक किया गया।
- ओपनकोड अब टर्मिनल की ऊंचाई में बदलाव का अनुसरण करता है और कीबोर्ड बंद होने या फोन घूमने पर पूरी प्रयोग करने योग्य स्क्रीन को भर देता है।
- Kali और Ubuntu पैकेज स्क्रिप्ट द्वारा विरासत में मिले अमान्य Android`TMPDIR`को ठीक किया गया।
- बाधित`ssl-cert`, PostgreSQL,`sysstat`, Metasploit और Kali टूल इंस्टॉलेशन की मरम्मत की गई।
- एंड्रॉइड हार्डवेयर डेटा के लिए एक PROoot-सुरक्षित`systemd-hwdb`संगतता परत जोड़ा गया।
- ओपनकोड इंस्टॉलेशन को ठीक किया गया और काली कमांड पथ में`/root/.local/bin`जोड़ा गया।
- काली शेल प्रॉम्प्ट और होस्टनाम को`root@kali`प्रदर्शित करने के लिए बाध्य किया।
- मुख्य मेनू में एक नया **README.md** पृष्ठ जोड़ा गया।
- मार्कडाउन शीर्षक, सूचियाँ, लिंक, नोट्स और टर्मिनल कोड ब्लॉक ऐप के अंदर प्रस्तुत किए गए हैं।
- प्रत्येक कमांड ब्लॉक में एक **कॉपी** बटन होता है।
- दस्तावेज़ चयनित ऐप भाषा का अनुसरण करता है और इसमें अंग्रेजी फ़ॉलबैक भी शामिल है।
- काली रोलिंग रिपॉजिटरी और लापता पैकेज इंडेक्स अब स्वचालित रूप से तैयार किए जाते हैं।
- रूट फ़ाइल सिस्टम को दोबारा डाउनलोड किए बिना मौजूदा काली इंस्टॉलेशन की मरम्मत की जा सकती है।
- काली अब अपने स्वयं के बैनर और एक स्थिर`root@kali`होस्टनाम के साथ खुलता है।
- काली में`wget`,`curl`,`git`,`nano`, Python, pip, नेटवर्किंग टूल और सर्टिफिकेट तैयार किये जाते हैं।
- नेटिव ARM64 PTY समर्थन जॉब-कंट्रोल,`su`, टर्मिनल आकार बदलने और बार-बार सत्र बंद होने की समस्याओं को ठीक करता है।

## लोरा एआई उपकरण

मुख्य मेनू से **लोरा एआई** चुनें, एक प्रदाता से जुड़ें और एक प्रोजेक्ट फ़ोल्डर चुनें। एजेंट इन प्रोजेक्ट-स्कोप्ड टूल को उजागर करता है:

```text
list_files      read_file        search_files
write_file      replace_in_file  create_directory
delete_file     delete_directory move_path
rename_path     set_permissions
```

कस्टम प्रदाताओं को OpenAI-संगत`/v1/chat/completions`एंडपॉइंट को उजागर करना होगा। गेटवे और स्व-होस्ट की गई सेवाओं के लिए समापन बिंदु और मॉडल फ़ील्ड संपादन योग्य बने रहते हैं।

## पहली स्थापना

उबंटू अनिवार्य है. Node.js/npm और Python वैकल्पिक हैं और इन्हें सेटअप के दौरान चुना जा सकता है।

1. एक उबंटू संस्करण चुनें।
2. वैकल्पिक रूप से एक Node.js/npm संस्करण चुनें।
3. वैकल्पिक रूप से एक पायथन संस्करण चुनें।
4. **सेटअप इंस्टॉल करें** दबाएं और लोराकोड को चालू रखें।
5. प्रत्येक घटक का अपना प्रतिशत प्रगति बार और पृष्ठभूमि टर्मिनल आउटपुट होता है।

## फ़ोन संग्रहण पहुंच

इसे उबंटू टर्मिनल के अंदर चलाएँ। लोराकोड एंड्रॉइड स्टोरेज सेटिंग्स खोलता है, अनुमति की प्रतीक्षा करता है और स्वचालित रूप से जारी रहता है।

```bash
loracode-setup-storage
```

उपलब्ध माउंट पॉइंट:

- `/sdcard`- साझा फ़ोन संग्रहण।
- `/storage`- एंड्रॉइड स्टोरेज वॉल्यूम।
- `/hostdata`- निजी लोराकोड ब्रिज फ़ाइलें।

## उबंटू पैकेज कमांड

जब सिस्टम पैकेज को रूट एक्सेस की आवश्यकता हो तो`su -`के साथ स्थानीय खाता पासवर्ड का उपयोग करें।

```bash
su -
pkg update
pkg upgrade
pkg install git curl wget nano
pkg search python
pkg list-installed
pkg uninstall package-name
pkg repair
exit
```

मानक डेबियन कमांड भी समर्थित हैं:

```bash
apt update
apt install package-name
apt-get -f install -y
dpkg --configure -a
```

## नोड.जेएस और एनपीएम

```bash
node --version
npm --version
npm install
npm install package-name
npm install -g package-name
npx package-name
```

वैश्विक एनपीएम मॉड्यूल स्थानीय खाते के अंतर्गत संग्रहीत होते हैं, इसलिए वे एंड्रॉइड सिस्टम फ़ोल्डर्स में लिखे बिना उपयोग योग्य बने रहते हैं।

### ओपनकोड

OpenCode आधिकारिक ARM64 रिलीज़ और Android HTTPS डाउनलोड ब्रिज का उपयोग करता है:

```bash
npm install -g opencode-ai
opencode --version
opencode
```

## पायथन, पिप और आभासी वातावरण

```bash
python3 --version
pip3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install package-name
deactivate
```

वर्चुअल वातावरण का उपयोग करने की अनुशंसा की जाती है क्योंकि यह प्रोजेक्ट पैकेजों को उबंटू सिस्टम पैकेजों से अलग रखता है।

## काली लिनक्स ARM64

उबंटू टर्मिनल से काली को स्थापित या मरम्मत करें:

```bash
kali-install
```



इनमें से किसी भी उपनाम का उपयोग करके काली खोलें:

```bash
kali
nethunter
nh
```

परिवेश और उपलब्ध आदेशों की जाँच करें:

```bash
kali --version
uname -m
wget --version
curl --version
git --version
python3 --version
```

काली पैकेज प्रबंधन:

```bash
pkg update
pkg upgrade
pkg install package-name
pkg search package-name
pkg list-installed
pkg repair
kali-update
```

काली टूल प्रोफाइल:

```bash
kali-tools core
kali-tools top10
kali-tools default
kali-tools everything --yes
```

`everything`को दसियों गीगाबाइट की आवश्यकता हो सकती है। इसका उपयोग करने से पहले निःशुल्क संग्रहण की जाँच करें। काली से उबंटू टर्मिनल पर लौटने के लिए`exit`टाइप करें।

## टर्मिनल अनुकूलन

```bash
loracode-set-font /sdcard/font.ttf
loracode-reset-font
loracode-set-banner /sdcard/banner.txt
loracode-hide-banner
```

एप्लिकेशन चालू रहने के दौरान टर्मिनल कई सत्रों, एएनएसआई रंगों, इंटरैक्टिव संकेतों, कीबोर्ड शॉर्टकट्स, टर्मिनल आकार बदलने और पृष्ठभूमि सत्रों का समर्थन करता है।

## समस्या निवारण

### एक पैकेज स्थापना बाधित हो गई थी

```bash
su -
pkg repair
dpkg --configure -a
apt-get -f install -y
pkg update
exit
```

### काली का कहना है कि पैकेज में कोई इंस्टॉलेशन उम्मीदवार नहीं है

उबंटू पर लौटें और एक बार मरम्मत चलाएं:

```bash
exit
kali-install
kali
pkg update
```

### नया टर्मिनल सत्र तुरंत बंद हो जाता है

मौजूदा एप्लिकेशन पर नवीनतम LoraCode APK इंस्टॉल करें। ARM64 PTY ब्रिज और सत्र जीवनचक्र सुधार संस्करण 3.31 से आगे से शामिल किए गए हैं।

### भंडारण नजर नहीं आ रहा है

```bash
loracode-setup-storage
ls -la /sdcard
ls -la /storage
```

## जड़हीन सीमाएँ

काली स्टॉक एंड्रॉइड पर PRoot के माध्यम से चलता है। कमांड-लाइन पैकेज काम करते हैं, लेकिन वाई-फाई मॉनिटर मोड/इंजेक्शन, एचआईडी अटैक, डायरेक्ट यूएसबी हार्डवेयर एक्सेस, कर्नेल मॉड्यूल और अन्य कर्नेल-निर्भर सुविधाओं के लिए एक रूटेड डिवाइस और एक संगत कस्टम कर्नेल की आवश्यकता होती है।
